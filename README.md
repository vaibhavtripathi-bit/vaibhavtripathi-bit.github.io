# Vaibhav Tripathi Portfolio

Static portfolio website for GitHub Pages.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## GitHub Pages

This repository is intended to be published as the account-level GitHub Pages site:

- Repository name: `vaibhavtripathi-bit.github.io`
- Public URL: `https://vaibhavtripathi-bit.github.io/`
- Publishing source: `main` branch, repository root

The site content is based on Vaibhav Tripathi's mobile architect resume.

The public site includes a downloadable resume PDF at:

`assets/Vaibhav_Tripathi_Mobile_Architect.pdf`
